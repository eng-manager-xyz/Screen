# Button — sizes

<iframe src="../../assets/ui/button-sizes.html" width="100%" height="120" frameborder="0"></iframe>

`Sm` (28px), `Md` (34px, default), `Lg` (40px), plus a disabled state shown
on the right.

Sizes scale font size, padding, and overall height in lockstep so that the
optical mass scales linearly. The disabled state is just `opacity: 0.5` +
`cursor: not-allowed` — variant-agnostic.
