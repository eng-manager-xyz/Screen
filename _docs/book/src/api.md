# API reference

The full rustdoc is generated by `cargo doc` and mounted under `api/`.

- [`wisp`](./api/wisp/index.html) — the renderer.
- [`wisp-storybook`](./api/wisp_storybook/index.html) — wgpu story gallery
  (lib + bin + headless exporter).
- [`ui-storybook`](./api/ui_storybook/index.html) — Leptos UI gallery
  (lib + headless exporter).
- [`screen-app`](./api/screen_app/index.html) — the Tauri shell.

Regenerate with `just docs`. For broken-link enforcement, `just docs-strict`.
