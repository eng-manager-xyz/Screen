# Storybook + book consolidation

Every M-ANIM primitive ships with three artefacts:

1. **Rust code** under `crates/wisp-animation/src/`.
2. **An mdBook chapter** under
   `_docs/wisp-animation-book/src/chunks/` — the page you're
   reading is one of those.
3. **A WebGPU demo** in `wisp-chart-web` reachable at
   `https://eng-manager-xyz.github.io/Screen/wisp-chart/demo/?animate=<kind>`,
   plus a committed hero PNG fallback under
   `_docs/wisp-animation-book/src/assets/wisp-animation/`.

This chapter is the meta page that documents the convention; the
work itself is folded into each per-feature chapter.

## Convention recap

```admonish info title="Per-feature deliverable shape"
For every M-ANIM ticket:

- **Code** lives in its own module (`tween.rs`, `spring.rs`, …)
  exporting one primitive type. Every public item has a doc
  comment.
- **Tests** live alongside the module in a `#[cfg(test)] mod
  tests`. Boundary, midpoint, and any feature-specific
  invariants.
- **Chapter** at `src/chunks/<feature>.md` follows the same
  shape: one-paragraph intro → iframe + PNG hero → API snippet
  → admonish callouts → "Test invariants" list → source link.
- **WASM demo** is one variant on `AnimationKind` + one arm in
  `setup_animation` in `crates/wisp-chart-web/src/web.rs`. The
  arm captures the chart fixture + driver + per-frame mutator
  closure; the rAF infrastructure is shared.
- **Hero PNG** is generated by a `render_*_hero` integration
  test that uses the same code path the live demo uses,
  rendered to an offscreen `RenderTexture` and saved under
  `assets/wisp-animation/`.
```

## Gallery

A live cross-feature gallery isn't in v0.1; readers navigate via
the SUMMARY sidebar. The per-feature iframe is reachable from
the top of every chapter — open in a new tab for a full-bleed
view of any animation.

## Test invariants enforced by `just gate`

- **snapshots-check** — every chapter's referenced asset under
  `assets/` must exist as a committed file (the
  `render_*_hero.rs` tests regenerate them).
- **mermaid-check** — no ASCII diagrams; all of this book's
  chapters use prose + GFM tables (no diagrams needed).
- **pages-url-check** — every absolute URL uses the correct
  case (`/Screen/wisp-animation/...`).
