# API reference

Generated rustdoc for the `wisp` crate is published alongside this
book under [`./api/`](./api/wisp/index.html). It includes every
public type, trait, function, and constant in the renderer.

The rustdoc and this book share a deployment pipeline: every push
to `main` builds both and pushes them to the same GitHub Pages
site, so the link above is always in sync with the rendered
chapters.

```admonish tip title="Searching the API"
The rustdoc search bar (press `S` in the rustdoc UI) is faster
than scrolling. Bookmark `./api/wisp/index.html` if you find
yourself there often.
```
